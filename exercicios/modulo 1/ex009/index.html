Trabalhando com listas

Listas Ordenadas

Para criar listas ordenadas, segue a sintaxe

            <ol>
            <li>Acordar</li>
            <li>Comer</li>
            <li>Dormir</li>
            </ol>

Saída:

  1. Acordar
  2. Comer
  3. Dormir

Listas Não Ordenadas

Para criar listas não ordenadas, segue a sintaxe

            <ul>
            <li>Acordar</li>
            <li>Comer</li>
            <li>Dormir</li>
            </ul>

Saída:

  • Acordar
  • Comer
  • Dormir

Listas Mistas

Tem também como misturar as listas, tipo assim:

  • Manhã
    1. Acordar
    2. Se arrumar para trabalhar
    3. Ir para o trabalho
  • Tarde
    1. Chegar em casa
    2. Se arrumar para faculdade
    3. Ir para faculdade
  • Noite
    1. Chegar em casa
    2. Se arrumar para dormir
    3. Dormir
