Principais Formatações em HTML

Negrito / Destaque

Não semântico <b>.

É semântico <strong>.

Exemplo: Eu queria um cavalo da cor preta.

Itálico / Ênfase

Não semântico <i>.

É semântico <em>.

Exemplo: Eu queria falar em itálico.

Texto Marcado

Usando a tag <mark>.

Exemplo: Eu quero guardar isso aqui para eu poder ler depois.

Texto grande e pequeno

Temos a tag obsoleta (ou quase) <big>, e a tag <small>.

Exemplo: Um avião é grande, enquanto uma formiga é pequena.

Texto Deletado

Usando a tag <del>.

Exemplo: Eu vou falar um monte de asneira, tipo como você é tonto, mas desconsidera isso.

Texto Inserido

Usando a tag <ins>.

Exemplo: Eu vou falar um monte de asneira, tipo como você é tonto, e considere isso.

Texto Sobrescrito

Usando a tag <ins>.

Exemplo: 22 é igual a 4.

Texto Subescrito

Usando a tag <ins>.

Exemplo: A fórmula da água é H2O.
